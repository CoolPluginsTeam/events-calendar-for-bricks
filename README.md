# Events Calendar for Bricks Builder

A WordPress plugin that adds a custom **Events Widget** Bricks element (`ecbb-events-loop`) for The Events Calendar: list (Style 1 / Style 2), grid layout, and configurable event parts.

## Installation

1. Upload the `ecbb` folder to the `/wp-content/plugins/` directory.
2. Activate the plugin through the 'Plugins' menu in WordPress.
3. The custom "Events Typography" element will be available in Bricks Builder.

## Usage

In Bricks Builder, add the **Events Widget** element to your page. Choose list or grid, pick a list style when applicable, and configure event parts in the repeater.

## Requirements

- WordPress 5.0 or higher
- Bricks theme
- The Events Calendar plugin
